# TripMate

트립메이트는 동행자와 함께 여행 일정과 준비물을 관리하는 Android 앱입니다.

## APK 다운로드

휴대폰에서 아래 링크를 누르면 APK를 직접 다운로드할 수 있습니다.

[TripMate v0.1.0 APK 다운로드](https://github.com/kcycoding/tripmate/raw/refs/heads/master/releases/v0.1.0/tripmate-v0.1.0-debug.apk)

릴리즈 노트는 아래에서 확인할 수 있습니다.

[TripMate v0.1.0 릴리즈 노트](docs/release_notes/v0.1.0.md)

## 설치 방법

1. 휴대폰에서 APK 다운로드 링크를 엽니다.
2. `tripmate-v0.1.0-debug.apk` 파일을 다운로드합니다.
3. 다운로드한 APK 파일을 엽니다.
4. Android가 `알 수 없는 앱 설치` 권한을 요구하면 허용합니다.
5. 설치 후 Google 계정으로 로그인합니다.

## 주요 기능

- Google 로그인
- 여행 생성, 수정, 삭제
- 초대 코드 기반 동행자 참여
- 동행자 일정/준비물 공동 관리
- Day별 일정 관리
- 일정 순서 변경
- 준비물 체크리스트
- 외부 지도 앱 실행
  - Google 지도
  - 네이버지도 앱 또는 네이버 지도 웹
