# 주요 워크플로우

## 첫 실행

1. 사용자가 앱을 실행한다.
2. 앱이 로그인 상태를 확인한다.
3. 로그인되어 있지 않으면 로그인 화면을 표시한다.
4. Google 로그인을 완료한다.
5. 사용자 정보를 저장하거나 갱신한다.
6. 여행 목록 화면으로 이동한다.

## 여행 생성

1. 사용자가 여행 생성 버튼을 누른다.
2. 여행 제목, 여행지, 기간, 통화, 지도 앱 설정을 입력한다.
3. 앱이 입력값을 검증한다.
4. 여행 문서를 생성한다.
5. 초대 코드를 생성한다.
6. 생성자를 owner 멤버로 등록한다.
7. 여행 상세 화면으로 이동한다.

## 초대 코드로 여행 참여

1. 동행자가 Google 로그인을 한다.
2. 초대 코드 참여 화면에서 코드를 입력한다.
3. 앱이 초대 코드에 해당하는 여행을 찾는다.
4. 이미 멤버이면 여행 상세 화면으로 이동한다.
5. 멤버가 아니면 member 역할로 등록한다.
6. 여행 상세 화면으로 이동한다.

## 일정 추가

1. 사용자가 Day별 일정 화면에서 일정 추가를 누른다.
2. 날짜, 시간, 제목, 장소, 비용, 카테고리, 이동/소요 시간 메모를 입력한다.
3. 앱이 날짜가 여행 기간 안인지 확인한다.
4. 앱이 기본 통화와 환율을 기준으로 원화 환산 금액을 계산한다.
5. Firestore에 일정 항목을 저장한다.
6. 모든 멤버의 일정 화면에 변경 사항이 반영된다.

## 일정 수정

1. 사용자가 일정 카드의 수정 버튼을 누른다.
2. 일정 수정 화면에서 내용을 변경한다.
3. 날짜가 여행 기간 밖이면 저장할 수 없다.
4. 저장 시 `updatedBy`, `updatedAt`을 갱신한다.
5. 모든 멤버에게 변경 사항이 반영된다.

## 일정 삭제

1. 사용자가 일정 삭제 버튼을 누른다.
2. 앱이 삭제 확인 다이얼로그를 표시한다.
3. 사용자가 확인하면 일정 문서를 삭제한다.
4. 모든 멤버에게 변경 사항이 반영된다.

## 일정 순서 변경

1. 사용자가 일정 카드의 위/아래 버튼을 누른다.
2. 같은 날짜 안에서 대상 일정과 인접 일정의 `order` 값을 조정한다.
3. 변경된 순서가 모든 멤버에게 반영된다.

## 외부 지도 앱 실행

1. 사용자가 일정 카드의 지도 버튼을 누른다.
2. 앱이 여행의 기본 지도 앱 설정을 확인한다.
3. 장소명 또는 주소를 쿼리로 만든다.
4. 설정된 외부 지도 앱을 실행한다.
5. 앱이 설치되어 있지 않으면 대체 동작을 실행한다.

## 준비물 추가 및 체크

1. 사용자가 준비물 화면에서 항목을 입력한다.
2. 앱이 준비물 문서를 생성한다.
3. 멤버 누구나 체크 상태를 바꿀 수 있다.
4. 변경 사항은 모든 멤버에게 반영된다.

## 여행 기간 수정

1. owner가 여행 설정에서 시작일 또는 종료일을 수정한다.
2. 앱이 기존 일정 중 새 기간 밖에 있는 항목을 확인한다.
3. 기간 밖 일정이 있으면 날짜 재선택 안내를 표시한다.
4. 사용자가 각 일정의 새 날짜를 선택한 뒤 저장한다.
5. 모든 일정이 새 여행 기간 안에 있어야 변경을 완료한다.
