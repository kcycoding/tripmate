# TripMate v0.1.0 Release Notes

Release date: 2026-05-27
APK: [tripmate-v0.1.0.apk](https://github.com/kcycoding/tripmate/releases/download/v0.1.0/tripmate-v0.1.0.apk)

## Highlights

- Google 로그인 기반으로 앱 사용 가능
- Firestore에 사용자 정보, 여행, 일정, 준비물 저장 가능
- 여행 생성, 수정, 삭제 지원
- 초대 코드로 동행자 여행 참여 가능
- 동행자 일정과 준비물 추가, 수정, 삭제 가능
- Day별 전체 일정 보기와 일정 없는 Day 표시 지원
- 일정 항목 위/아래 순서 변경 지원
- 여행별 준비물 체크리스트 관리 가능
- 일정 장소에서 외부 지도 앱 실행 가능
  - Google 지도 앱 실행
  - 네이버지도 앱 실행 시도, 미설치 시 네이버 지도 웹으로 이동
- Android 앱 형태의 상단 아이콘 뒤로가기 적용
