# TripMate v0.1.0 Release Notes

Release date: 2026-05-27
APK: `releases/v0.1.0/tripmate-v0.1.0-debug.apk`

## Highlights

- Google 로그인 기반으로 앱을 사용할 수 있습니다.
- Firestore에 사용자 정보, 여행, 일정, 준비물이 저장됩니다.
- 여행 생성, 수정, 삭제를 지원합니다.
- 초대 코드로 동행자가 여행에 참여할 수 있습니다.
- 동행자도 일정과 준비물을 추가, 수정, 삭제할 수 있습니다.
- Day별 전체 일정 보기와 일정 없는 Day 표시를 지원합니다.
- 일정 항목의 위/아래 순서 변경을 지원합니다.
- 준비물 체크리스트를 여행별로 관리할 수 있습니다.
- 일정 장소에서 외부 지도 앱을 실행할 수 있습니다.
  - Google 지도 앱 실행
  - 네이버지도 앱 실행 시도, 미설치 시 네이버 지도 웹으로 이동
- 화면 상단에 Android 앱 형태의 아이콘 뒤로가기를 적용했습니다.

## Included In This APK

- Package name: `com.tripmate.app`
- Version name: `0.1.0`
- Version code: `1`
- Build type: Debug APK

## Install Notes

1. Android 휴대폰에서 APK 파일을 다운로드합니다.
2. 파일을 열어 설치합니다.
3. Android가 알 수 없는 앱 설치 권한을 요구하면 허용합니다.
4. 앱 실행 후 Google 계정으로 로그인합니다.

## Known Notes

- 이 APK는 Play Store 배포용 서명 APK가 아니라 개발/테스트용 Debug APK입니다.
- 동행자 공유 기능을 사용하려면 동행자도 앱 설치와 Google 로그인이 필요합니다.
- Firestore 보안 규칙은 Firebase Console에 게시되어 있어야 합니다.
