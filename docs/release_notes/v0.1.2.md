# TripMate v0.1.2 Release Notes

Release date: 2026-05-29
APK: [tripmate-v0.1.2.apk](https://github.com/kcycoding/tripmate/releases/download/v0.1.2/tripmate-v0.1.2.apk)

## Highlights

- 실제 사용 금액을 관리하는 예산 기능 추가
- 일정의 예상 비용과 실제 예산을 별도 데이터로 분리
- 예산 추가/수정/삭제 기능 추가
- 예산 추가 시 기존 일정 선택 또는 직접 입력 지원
- 예산 합계를 전체, 날짜별, 카테고리별, 항목별로 표시
- 해외 통화 사용 시 입력된 환율 기준 원화 금액 함께 표시
- 일정 편집 모드에서 위/아래 이동 버튼 유지
- 일정 편집 모드에서 드래그 순서 변경과 삽입 위치 프리뷰 추가
- 삼성/Android 시스템 뒤로가기 버튼으로 일정 편집 모드 취소 지원
- Firestore expenseItems 보안 규칙 추가
