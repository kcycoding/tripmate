# TripMate v0.1.1 Release Notes

Release date: 2026-05-29
APK: [tripmate-v0.1.1.apk](https://github.com/kcycoding/tripmate/releases/download/v0.1.1/tripmate-v0.1.1.apk)

## Highlights

- 여행 상세 화면을 `일정 관리 | 준비물` 탭 구조로 분리
- 일정 관리 탭에 여행 시작일~종료일 기준 날짜 선택 영역 추가
- 선택한 날짜의 일정만 표시되도록 전체 일정 보기 개편
- 일정 추가를 우측 하단 FAB 버튼으로 변경
- 일정 추가/수정을 별도 화면에서 관리하도록 변경
- 일반 일정 카드에서 위/아래 텍스트 버튼 제거
- 일정 편집 모드 추가
  - 일정 카드를 길게 눌러 편집 모드 진입 가능
  - 왼쪽 체크박스로 여러 일정 선택 후 삭제 가능
  - 오른쪽 위/아래 아이콘으로 같은 날짜 안에서 순서 변경 가능
- 준비물 화면을 별도 탭으로 분리
