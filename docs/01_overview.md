# 트립메이트 앱 개요

## 목적

트립메이트는 여행 동행자들이 함께 여행 일정과 준비물을 관리하는 Android 앱이다. 사용자는 여행을 생성하고, 초대 코드로 동행자를 초대하며, 여행 기간에 따라 자동 구성된 Day별 일정표를 함께 편집할 수 있다.

## 핵심 가치

- 여행 일정을 날짜별, 시간별로 한눈에 확인한다.
- 동행자 모두가 일정과 준비물을 함께 관리한다.
- 장소 정보는 외부 지도 앱으로 바로 연결한다.
- 모바일 사용을 우선하여 여행 전과 여행 중 모두 쉽게 사용할 수 있게 한다.

## 1차 MVP 방향

- Android 앱으로 개발한다.
- Google 로그인 기반으로 사용자를 식별한다.
- Firebase를 사용해 여행, 일정, 준비물, 멤버 정보를 저장하고 공유한다.
- 앱 안에 지도 화면을 만들지 않고, 네이버지도 또는 구글지도 앱을 실행한다.
- 이동 시간 자동 계산은 제외하고, 사용자가 직접 이동/소요 시간 메모를 입력한다.

## 앱 이름

앱 이름은 `트립메이트`로 한다.

영문 표기는 필요 시 `TripMate`를 사용한다.
