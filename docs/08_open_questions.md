# 구현 전 확인 질문

현재 확정된 내용은 MVP 구현에 충분하다. 다만 실제 구현 전에 아래 항목은 한 번 더 결정하면 좋다.

## 앱 패키지명

예시:

- `com.tripmate.app`
- `com.yourname.tripmate`

Google 로그인과 Firebase 설정에 필요하다.

## Firebase 프로젝트

확인 필요:

- 새 Firebase 프로젝트를 만들지
- 기존 Firebase 프로젝트를 사용할지
- 프로젝트 이름을 `TripMate`로 할지

## 구글 로그인 테스트 계정

확인 필요:

- 개발 중 사용할 Google 계정
- 동행자 테스트용 두 번째 Google 계정

## 초대 코드 형식

추천:

- 영문 대문자와 숫자 조합 6자리
- 예: `AB12CD`

확인 필요:

- 초대 코드를 사용자가 직접 다시 생성할 수 있게 할지
- 초대 코드 만료 기간을 둘지

## 지도 앱 대체 동작

확인 필요:

- 선택한 지도 앱이 설치되어 있지 않으면 웹 브라우저로 열지
- Play Store로 이동할지
- 사용자에게 다른 지도 앱을 선택하게 할지

추천:

- 웹 브라우저 대체 실행 후 실패하면 Play Store 안내

## 환율 입력 방식

확정:

- 1차 MVP에서는 사용자가 직접 입력한다.

추가 확인:

- 여행 중 환율을 수정하면 기존 일정의 원화 환산 금액도 다시 계산할지
- 아니면 이후 입력되는 일정부터 새 환율을 적용할지

추천:

- 환율 수정 시 전체 일정 비용을 다시 계산할 수 있는 버튼을 제공한다.

## 여행 설정 권한

현재 추천:

- owner만 여행 기본 정보, 지도 앱, 환율, 초대 코드, 멤버를 관리한다.
- member는 일정과 준비물만 관리한다.

확인 필요:

- 동행자도 여행 기본 정보를 수정할 수 있게 할지
