# 도메인 모델

## User

Google 로그인으로 식별되는 앱 사용자다.

주요 역할:

- 여행 생성
- 초대 코드로 여행 참여
- 일정 관리
- 준비물 관리

## Trip

사용자가 생성한 여행 단위다.

Trip은 여행 기간, 목적지, 멤버, 기본 통화, 기본 지도 앱 설정을 가진다.

## TripMember

Trip에 참여한 사용자 정보다.

역할:

- `owner`: 여행 생성자
- `member`: 여행 동행자

1차 MVP에서는 모든 멤버가 일정과 준비물을 편집할 수 있다. 단, 여행 삭제와 멤버 관리는 owner만 가능하다.

## ScheduleItem

특정 여행의 특정 날짜에 속하는 일정 항목이다.

일정 항목은 시간, 장소, 제목, 비용, 카테고리, 이동/소요 시간 메모를 가진다.

## PackingItem

여행별 공용 준비물 항목이다.

멤버 누구나 추가하거나 체크할 수 있다.

## InviteCode

여행 참여를 위한 코드다.

동행자는 초대 코드를 입력해 TripMember로 등록된다.

## MapProvider

외부 지도 앱 설정이다.

지원 값:

- `naver`
- `google`

여행마다 기본 지도 앱을 저장하며, 여행 설정에서 수정할 수 있다.

## Currency

여행 비용 입력 기준 통화다.

국내 여행은 원화만 사용한다. 해외 여행은 기본 통화와 원화 환산 금액을 함께 표시한다.
