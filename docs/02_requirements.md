# 요구사항

## 사용자

- 여행 생성자
- 여행 동행자

모든 사용자는 Google 로그인을 통해 앱을 사용한다.

## 인증

- Google 로그인으로 시작한다.
- 로그인하지 않은 사용자는 여행 목록, 일정, 준비물에 접근할 수 없다.
- 로그인 후 사용자의 이름, 이메일, 프로필 이미지, UID를 저장한다.

## 여행 관리

사용자는 여행을 생성할 수 있다.

여행 생성 시 입력 항목:

- 여행 제목
- 여행지
- 시작일
- 종료일
- 메모
- 기본 통화
- 원화 환산용 환율
- 기본 외부 지도 앱

여행 생성자는 여행을 수정하거나 삭제할 수 있다.

여행 기간 수정 시 기존 일정이 변경된 기간 밖에 있으면 사용자가 다시 날짜를 선택하도록 안내한다.

## 여행 공유

- 여행마다 초대 코드를 생성한다.
- 동행자는 초대 코드를 입력해 여행에 참여한다.
- 여행에 참여한 사용자는 해당 여행의 멤버가 된다.
- 멤버는 일정과 준비물을 추가, 수정, 삭제할 수 있다.
- 여행 삭제, 초대 코드 재생성, 멤버 제거는 여행 생성자만 할 수 있다.

## 날짜별 일정 관리

- 여행 시작일과 종료일을 기준으로 Day 1부터 Day N까지 자동 구성한다.
- 일정이 없는 Day도 항상 표시한다.
- 각 Day에는 실제 날짜와 요일을 함께 표시한다.
- 일정은 시간순으로 자동 정렬한다.
- 같은 날짜 안에서 사용자가 위/아래 이동으로 순서를 조정할 수 있다.

## 일정 항목 관리

일정 항목은 다음 정보를 가진다.

- 시간
- 장소명
- 주소 또는 지도 검색어
- 일정 제목
- 메모
- 예상 비용
- 통화
- 원화 환산 금액
- 카테고리
- 이동/소요 시간 메모

카테고리:

- 관광
- 식사
- 이동
- 숙소
- 쇼핑
- 기타

## 외부 지도 앱 연동

- 앱 안에 지도는 표시하지 않는다.
- 여행 생성 또는 여행 설정에서 기본 지도 앱을 선택한다.
- 선택 가능한 기본 지도 앱은 네이버지도와 구글지도로 한다.
- 일정의 장소명 또는 주소를 기반으로 선택된 외부 지도 앱을 실행한다.
- 기본 지도 앱 설정은 여행마다 수정할 수 있다.

## 준비물

- 준비물은 여행별로 따로 관리한다.
- 여행 멤버는 준비물을 추가, 체크, 체크 해제, 삭제할 수 있다.
- 준비물은 공용 체크리스트로 관리한다.

## 비용과 환율

- 여행별 기본 통화를 선택할 수 있다.
- 국내 여행인 경우 환율 입력은 필요 없다.
- 해외 여행인 경우 사용자가 환율을 직접 입력한다.
- 일정 비용은 기본 통화와 원화 환산 금액을 함께 표시할 수 있어야 한다.

## 제외 기능

1차 MVP에서는 다음 기능을 제외한다.

- 앱 내부 지도 표시
- 이동 시간 자동 계산
- 장소 검색 API 연동
- AI 일정 추천
- PDF 또는 이미지 내보내기
- 푸시 알림
